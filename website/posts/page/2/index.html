Nobody Can Revoke an Intermediate: Java Gets a 9.1 and certifi Pulls Four Roots to Block Eight Certificates

Oracle published an out-of-cycle Security Alert on 21 October 2026 for CVE-2026-91403, CVSS 3.1 9.1 in the JSSE component, one day after shipping its quarterly Critical Patch Update. The fix is not a code change: it deletes the eMudhra intermediates from Java’s trust store. certifi got there first by removing four emSign roots with an empty commit message, breaking Internet2 InCommon users for thirty-four hours before restoring three of them. Temurin had to point its certdata updater at an NSS tag by hand. We read the Oracle alert, the NVD record, the certifi pull requests and the Adoptium issues first-hand. The common cause is stated outright by certifi’s maintainer: there is no facility for revoking an intermediate only.
