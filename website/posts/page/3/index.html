The Tag Was Clean: LiteLLM 1.107.0 Was Built From a Lookalike Fork of Its Own Repository

On 21 October 2026 the litellm 1.107.0 wheels on PyPI and every v1.107.0 container image shipped a credential stealer and an hourly remote-code loader. The payload is not in the v1.107.0 git tag. It sits in ten commits stacked on top of that tag inside a hyphenated lookalike repository, Berri-AI/litellm, which the private release pipeline of the project built from. BerriAI now says the releaser run was triggered and approved through the GitHub accounts of three engineers, apparently via stolen GitHub CLI OAuth tokens. The attacker commits even carry the green Verified badge, because GitHub signs anything committed in its web editor. We verified the commits, the registry state and the remediation timeline first-hand.
