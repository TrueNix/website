One Annotation Beats Every Flag: Podman’s CVSS 10.0 Sandbox Bypass Was a 2022 Feature, Found by Claude

CVE-2026-94603 reached NVD on 13 October 2026 at CVSS 10.0: any OCI image carrying the io.podman.annotations.checkpoint.runtime.name annotation made podman run silently discard the operator’s own sandbox flags, including --cap-drop=ALL. The cause was a convenience feature merged in December 2022 and shipped in v4.4.0, whose early return skipped the function that applies user security options. The fix is a revert, a breaking change, and a green e2e test turned red. Credited to ADA Logics using Anthropic’s Claude models.

Wrap It in a Dict and the Gate Opens: Crawl4AI’s CVE-2026-109237 Reads the Server’s Secrets

CVE-2026-109237, published to NVD on 12 October 2026, names an untrusted-config gate bypass in Crawl4AI 0.9.0 before 0.9.4.
