Thirty Dollar Signs Beat the Guard: CVE-2026-77474 Turns a Complexity Bug in dcg Into an Agent Fail-Open

CVE-2026-77474, published to NVD at 17:17:50Z on 16 October 2026, is a 7.1 uncontrolled-resource-consumption flaw in destructive_command_guard — the Rust PreToolUse hook that blocks destructive shell commands before AI coding agents run them.
