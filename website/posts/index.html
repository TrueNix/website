127.0.0.1.evil.com Passes the Allowlist: CVE-2026-102878 Lets Any Website Drive Your Browser Agent

CVE-2026-102878 (CVSS 4.0 base 8.6, CVSS 3.1 base 8.1) is an origin validation error in mcp-chrome-bridge through 1.0.31, the native host for the 12,456-star Chrome MCP Server. A one-line startsWith check treats http://127.0.0.1.evil.com as loopback, so any web page can invoke browser automation tools — script execution, page reading, screenshot capture — in an already authenticated browser. The issue has been open since 4 September 2026 and npm still serves 1.0.31.
