AWS Shipped the Fix in August and the Advisory in October — CVE-2026-97662 Turns a Git Ref Into a File Write

CVE-2026-97662, published 1 October 2026, is an argument injection in the AWS security-agent-mcp-server: base_ref lands on a git command line unvalidated, so a value like --output=PATH turns a read-only diff scan into an arbitrary file write that walks straight past the workspace-confinement control.
