Deleting the Record Did Not Delete the Secret: AfterDeleteBench Reconstructs Erased Data From Agent Memory 62–99% of the Time

arXiv:2610.31366, submitted 22 October 2026, audits what survives when an agent deletes a memory record. A single query recovered the deleted secret from Qwen2.5-7B-Instruct in roughly two thirds of cases while never-exposed controls recovered nothing. With no verbatim copy left and only separately stored components under a public composition rule, exact reconstruction succeeded in 62–99% of cases across Qwen, Mistral and Phi-3. Provenance-aware closure eliminated recovery; a literal write filter did not.

False Assurances Cost 19 Points, False Alarms Cost Nothing: arXiv:2610.32876 Measures Which Way LLM Auditors Bend

A study submitted 23 October 2026 ran 16,572 audits across eleven model configurations from four vendors, feeding LLM vulnerability auditors static-analysis notes that were sometimes fabricated. True evidence added +0.02 accuracy. Fabricated assurances that a missing check exists cut detection of real vulnerabilities by up to 19 points; fabricated alarms cost nothing and were disputed far more often. Prompt instructions did not reliably fix it; verifying each claim in a separate call recovered 12 points.
